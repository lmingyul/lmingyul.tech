港大与字节 Seed 开源 Laminar，一个面向 LLM 与长程 Agent 的异步 RL 后训练框架：不再让每条轨迹、每张 GPU 等最慢的一条，而是把生成、奖励、训练解耦流水起来。测试覆盖 Qwen3-Coder-30B-A3B（30.5B 总参/3.3B 激活）与 Qwen2.5 7B/32B/72B，跑在 64×H800 到 1024×H800 集群，推理用 vLLM、训练用 Megatron-LM 或 FSDP2。 [\[20\]](https://www.marktechpost.com/2026/11/24/bytedance-seed-laminar-async-rl-post-training-framework/)

### B4 ★★★★☆ vLLM 发布 vLLM-GR：专做生成式推荐推理，H20 上大 beam P99 369 ms（11-25）

〔B·推理与训练框架〕

![图源：vllm.ai 原文配图](https://vllm.ai/blog-assets/figures/2026-11-24-vllm-gr-announcement/vLLM-GR.jpg)

vLLM 官方在 X 上用 6 条串推发布 vLLM-GR：在 vLLM 引擎里加入 beam session，复用调度和 paged KV cache，多条 beam 共享 prompt KV，在设备端做 beam search 并按候选目录约束解码，通过 Python / HTTP / gRPC 返回候选序列和分数，支持 NVIDIA GPU 和华为 Ascend NPU，附 OneRec-1.7B 示例。官方基准：beam 256、输入 1024 token、batch 8 时，H20 上 P99 369.4 ms（SGLang 1280.1 ms、NVIDIA SID-GR 428.1 ms）；A100 batch 8 下 SID-GR 略快（199.0 vs 209.7 ms）。 [\[21\]](https://x.com/vllm_project/status/2125409455278059747)[\[22\]](https://vllm.ai/blog/2026-11-24-vllm-gr-announcement)[\[23\]](https://github.com/vllm-project/vllm-gr)

### E11 ★★☆☆☆ EON：用嵌入优化噪声复现检索意图，可绕过输入护栏（11-25）

*🏛 机构未注明 · Ankit Gupta, Christoph Adami, Emily Dolson · arXiv 2611.31344 · 11-25*
