# AI 集成类

- [Poe](https://poe.com/): 可以以积分的形式快速体验和使用到最新的 AI Model
- [LobeChat](https://lobehub.com/zh)：通过 API 调用不同的 AI Model，可以快速实现 AI 知识库、Agent，MCP 等功能
- Cherry Studio：跟 LobeChat 类似，也是可以通过API 调用不同的 AI Model，也有知识库、MCP 等功能

# 代码类

- [grep](https://grep.app/)：可以搜索 GitHub 上有类似功能的代码，速度非常快

# 可视化类

- [Transformer Explainer](https://poloclub.github.io/transformer-explainer/)：可视化 Transformer 处理流程，对理解 Transformer 有帮助
